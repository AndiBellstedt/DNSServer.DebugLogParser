# Integration with Analysis Tools

[← Back to index](index.md)

The parsed CSV output integrates with common analytics and reporting tooling.

## Microsoft Excel

- Open the CSV files directly for ad-hoc analysis, pivot tables, and charts.
- Use semicolon delimiter for automatic column separation in regions that use comma as decimal separator.

## Power BI

- Import CSV files to build dashboards showing DNS activity, top clients, query trends, and security insights.

## SQL databases

- Bulk load CSV files into SQL Server, PostgreSQL, or other databases for long-term storage and SQL-based analysis.

## SIEM systems

- Import parsed logs into Splunk, Elastic, or other SIEM platforms for correlation with other security events and automated alerting.

## Python / R / data science workflows

- Use the structured CSV data for anomaly detection or custom analytics (for example with pandas / scikit-learn).
